# Overview
This Userscript integrates U-Fret (ufret.jp) chord search and display directly into YouTube.
It allows guitar players to quickly access chords while watching music videos.
![screenshot](sample.jpg)
# Features
1. **保存(save)ボタン**
   When the save button is clicked, the scroll speed and videoId are stored in the Favorites tab.
   If the video’s URL matches the saved videoId, the saved chords will automatically be displayed in the Chords tab.
# Installation
1. **Install Tampermonkey**  
   - Chrome : [Tampermonkey](https://chromewebstore.google.com/detail/tampermonkey-%E3%83%99%E3%83%BC%E3%82%BF%E7%89%88/gcalenpjmijncebpfijmoaglllgpjagf)
   - Firefox : [Tampermonkey](https://addons.mozilla.org/ja/firefox/addon/tampermonkey/)

2. **Allow userscript**  
   Enable “Allow User Scripts” in the Extensions settings. For more details, see the official FAQ.
   [https://www.tampermonkey.net/faq.php?locale=ja&q=Q209](https://www.tampermonkey.net/faq.php?locale=en&q=Q209)

3. **Install youtube-ufret-chords-usersciprt**    
   You can install it [Here](https://github.com/grmpnk/youtube-ufret-chords-usersciprt/raw/refs/heads/main/userscript.user.js)
